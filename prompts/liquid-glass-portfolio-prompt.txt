# COLOR
Define the palette as named tokens and nothing else (no sizes, effects, or
structure). Every other style in the project must reference color only through
these tokens, never literal values.

Required tokens:
- Backgrounds: --bg, --bg-elevated
- Glass: --surface (translucent fill), --surface-hover
- Borders: --border, --border-strong
- Text: --text-primary, --text-muted
- Accent: --accent, --accent-glow
- Ambient light: --blob-1, --blob-2, --blob-3
- Cursor glow: --spotlight

Default preset, Monochrome Luxury:
- Background true black #050505, obsidian glass surfaces
- Borders icy silver / white at ~10% opacity
- Primary text white at ~90%, muted text white at ~60%
- Accent icy silver, glows white

Alternative presets (if I choose a custom accent): Emerald, Gold, or Midnight
Blue, each keeping the dark base and swapping only accent, glow, and blob tokens.

All text/background pairs must meet WCAG AA contrast. Provide each preset as a
switchable theme so changing it is a one-line edit.

# DESIGN
Look, feel, typography, and motion. Use color tokens only.

**Background: liquid ambient light**
- Deep background tint with slow-morphing, floating radial light blobs
  (animation named `liquid-morph`), 20-30s loops, soft blur ~80-120px, low
  opacity (~0.15-0.35), colored by the blob tokens.

**Glass panels**
- Translucent frosted panels: strong backdrop blur (~24px), very low-opacity
  fill (~2%) from --surface, 1px --border, large soft shadow, rounded
  corners (~16px).
- Fallback when backdrop blur is unsupported: opaque --bg-elevated.
- Limit simultaneously visible blurred surfaces (~6) for performance.

**Typography**
- Clean hierarchy using Inter (or my chosen font), generous letter-spacing on
  small labels, tight tracking on large headings, --text-primary for emphasis
  and --text-muted for secondary text. Fluid hero size (about 44px on mobile
  up to ~88px on desktop).

**Interactive spotlight**
- A cursor-tracking effect on glass cards: a subtle radial glow (~300px
  radius, colored by --spotlight) follows the cursor behind card content.
- Disabled on touch devices.

**Motion**
- Smooth, inertial page scrolling.
- Scroll-triggered staggered reveals on titles, cards, and section dividers:
  ~24px rise + fade, ~0.8s, ease-out, ~0.08s stagger.
- Hover transitions 200-300ms with no layout shift.
- Content must remain visible if animation code fails to load (set hidden
  start states in script, not in static styles).
- Respect reduced-motion preferences: disable blobs, smooth scrolling, and
  reveals.

**Icons**
- Inline vector icons (tech logos or feather-style line icons); no emoji icons.

# LAYOUT
Structure only: place the glass cards, pills, and other components defined
in DESIGN without redefining their appearance.

**Global**
- Mobile-first, fully responsive, no horizontal overflow, zero layout shift
  (reserve space for images and fonts).
- Suggested breakpoints: 640 / 768 / 1024 / 1280px; centered container
  (~1152px max); generous vertical section spacing.

**Sections, in order**
1. **Navbar**: fixed floating header with glass treatment; compacts on scroll;
   active-link indicator; scroll-progress bar at the top edge; collapses to a
   menu on small screens; anchor links account for the navbar's height.
2. **Hero**: minimalist layout, glowing badge indicator, two action buttons
   (Projects, Contact), ambient liquid lighting behind.
3. **About**: high-contrast grid of key highlights, domain focus, and
   operational metrics (2 columns on mobile, 4 on desktop).
4. **Skills**: 4 domain-specific glass boxes (e.g., Machine Learning,
   Systems & Backend), each holding hoverable pill items with vector icons
   (1 column mobile, 2 on tablet and up).
5. **Projects**: responsive grid of 1 / 2 / 3 columns (mobile / md / lg) with
   a gap of ~32px. Cards are uniform height with the same structure: a fixed
   16:9 image area, content block, and tags/links pinned to the bottom.
6. **Experience & Education**: vertical timeline or structured glass cards for
   roles, achievements, and academic credentials.
7. **Contact & Footer**: minimalist terminal-style contact card, quick
   email-copy button, social links, credit line.

**Structure and accessibility**
- Semantic landmarks, skip link, visible focus states, labels on icon-only
  buttons.
